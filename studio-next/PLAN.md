# ميكانيزم ستوديو — بناء جديد بـ Next.js

المرجع القديم (قراءة فقط): `studio/` (index.html + smart.js + render.html + sw.js + worker/).

## جرد الميزات القديمة (لازم كلها تتحافظ)
**أقسام الواجهة (11):** لوحة التحكم · المنتجات · استوديو البوستات · الصور · اعمل فيديو · مساعد المحتوى · المحرر · الوارد · التقويم · المظهر · الإعدادات والنسخ.
**البوستات/الصور:** ستايلات جاهزة، لوكات، ستايل مرجعي، خلفية، إطارات، ستيكرز، فلاتر، طبقات، نصوص وموشن، قص ومقاسات، صورة منتج احترافية، تصدير.
**الفيديو (المحرر اليدوي):** تايم لاين، مقطع محدد، سرعة متدرجة، ترجمة وكابشن، موشن جرافيك، أدوات ذكية، اختصارات.
**مونتاج ذكي (smart.js — الأهم):** فيديو خام ← صوت ← قص على السكتات (VAD) ← ترجمة الذكاء (video-ai) ← قالب «احترافي ذكي» (منطقة آمنة تيك توك/ريلز، أقصى عنصرين، ولا عنصر على الوش بـ MediaPipe Pose، اسم المنتج شريط مرة، كلام كلمة بكلمة، لوحات زجاجية) ← رسومات متحركة للأصناف (دراع/مجرى/مفصلة…) ← ملصقات ← تصدير MP4.
  + **قاموس مصطلحات** يتعلم من تصحيحاتك · **تصدير SRT** · **صورة غلاف** · رندر سحابي (mk_video_jobs + worker/render.mjs + render.html) · سكيل من لينك (mk_skill_jobs + worker/skill.mjs).
**عام:** دخول Supabase (JWT بيتجدد كل ساعة)، تخزين studio_kv، نسخ احتياطي وتلقائي، سجل أخطاء ونشر، ثيمات، هوية الشركة، PWA/أوفلاين، ربط ميتا، مراجعة استيراد PDF، RTL عربي.

## المراحل
1. **الأساس (اتبنى)** — Next.js RTL، هيكل بالـ 11 قسم، دخول Supabase، ثيمات، PWA، على الشكل النهائي الحالي (مش إعادة تنفيذ التاريخ).
2. **المنتجات + الهوية + الإعدادات/النسخ الاحتياطي.**
3. **مونتاج ذكي (الأهم):** نقل smart.js كموديولات (صوت/VAD، الذكاء، القوالب، الرسم، التصدير، القاموس، SRT، الغلاف) + نفس worker.
4. **استوديو البوستات والصور والمحرر.**
5. **مساعد المحتوى، الوارد، التقويم، لوحة التحكم، ربط ميتا.**
6. **صقل:** موبايل/آيفون، سرعة، مقارنة ميزة بميزة مع القديم، نشر (بعد موافقة عبده).

كل مرحلة تتختبر في المتصفح. مفيش push ولا نشر لحد ما عبده يقول.

> **قاعدة عبده:** كل مرحلة بتتبني على آخر شكل نهائي للقديم (الكود الحالي والمنشور) بكل ميزاته الحالية، من غير ما نعيد تعديلات الكوميتات القديمة واحد واحد. `git log` للفهم بس.
