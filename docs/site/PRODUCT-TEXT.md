# إزاي تكتب وصف المنتج عشان الموقع يفهمه

الموقع بيحوّل أي سطر شكله **«الاسم: القيمة»** لصف في جدول المواصفات. الصفوف دي بتستخدم في:
- جدول المواصفات في صفحة المنتج
- صفحة المقارنة
- فلاتر القسم (لو منتجين أو أكتر في نفس القسم ليهم نفس الخانة، زي «المقاس»، بتظهر فلتر بقيمها)

## القواعد
1. كل معلومة في سطر لوحدها.
2. اسم الخانة قصير (كلمة أو اتنين)، والقيمة قصيرة (أقل من ٧٠ حرف).
3. استخدم **نفس اسم الخانة** في كل المنتجات، عشان الفلاتر تشتغل:
   `المقاس` · `الطول` · `العرض` · `العمق` · `اللون` · `الخامة` · `النوع` · `القفلة` · `الحمل` · `البراند` · `المنشأ` · `يناسب`
4. اكتب القيمة بنفس الشكل في كل مرة، زي `45 سم` مش مرة `45سم` ومرة `٤٥ سنتي`.
5. الكلام العادي (المميزات والنصايح) يتكتب فوق أو تحت الجدول عادي.

## نموذج
```
سطر أو اتنين بيقولوا المنتج ده بيعمل إيه ولمين.
النوع: ...
المقاس: ...
الخامة: ...
اللون: ...
القفلة: سوفت كلوز
يناسب: ...
```

## مسودات للمنتجات الحالية (من الوصف الموجود بس، راجعها وكمّل الناقص)

**1248 — طقم جرار دولاب سوفت كلوز دلف قطاع المنيوم ودلف خشب**
```
طقم جرار لدولاب بدلف بتتحرك جنب بعض، بيقفل بهدوء ويحمي جنب الدولاب من الخبط.
النوع: جرار دولاب
القفلة: سوفت كلوز
يناسب: دلف قطاع ألمنيوم ودلف خشب
```

**1249 — ماجيك فاصوليا هازرد تركي شمال**
```
ماجيك كورنر لوحدة الركنة في المطبخ: الرفوف بتطلع برا الوحدة وبتستغل الركنة كلها.
النوع: ماجيك كورنر (فاصوليا)
البراند: هازرد
المنشأ: تركي
الاتجاه: شمال
عرض الوحدة: من 90 لـ 100 سم
أقل عمق: 50 سم
أقل ارتفاع داخلي: 54 سم
أقل عرض ضلفة: 45 سم
```

**P0876 — ميكانيزم جزامه معدن مجوز N**
```
ميكانيزم جزامة معدن مزدوج لتنظيم الجزم جوه الوحدات والدريسينج.
النوع: جزامة مجوز
الخامة: معدن
المقاس: (اكتبه)
```

**P0339 — درج خزنه مصفح متقسم 60 سم**
```
درج خزنة مصفح للدريسينج روم، بيتفتح بالبصمة أو بالأرقام، وجواه تقسيم مبطن للساعات والمجوهرات.
النوع: درج خزنة مصفح
المقاس: 60 سم (يركب في درج من بره لبره 60 سم)
الفتح: بصمة + أرقام سرية + مفتاح طوارئ
الكهربا: بطاريات + منفذ USB
اللون: رمادي غامق
```

**P0865 — مفصله بلاند كورنر هب**
```
مفصلة لضلفة الركنة العمياء في المطبخ، فيها مسامير ضبط للاتجاه والمستوى.
النوع: مفصلة بلاند كورنر
البراند: هب
يناسب: ركنة المطبخ
```

**P0684 — دولاب خزين سحاب 4 رف ستار اكس تركي**
```
دولاب خزين سحاب بيطلع كله لبرا وتوصل لكل حاجة فيه بسهولة.
النوع: دولاب خزين سحاب
عدد الرفوف: 4
البراند: ستار اكس
المنشأ: تركي
المقاس: (اكتبه)
```

**P1251 — جرار دولاب سوفت كلوز دلفه خشب اصلي**
```
جرار ألمنيوم أصلي للدولاب بقفلة سوفت كلوز. اوعى من التقليد: الأصلي أتقل وقطاعه أتخن.
النوع: جرار دولاب
القفلة: سوفت كلوز
الخامة: ألمنيوم
الأنظمة: 2 دلفة و3 دلفة
الطول: لحد 6 متر
يناسب: دلف خشب
```
